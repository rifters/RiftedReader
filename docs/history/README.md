# History Archive

This folder preserves how RiftedReader got to where it is: superseded roadmaps,
status snapshots, and change narratives. It exists so the journey is not lost —
and so it stops masquerading as current status.

Rules:

- Files here are **frozen snapshots**. They are never edited to "update" them;
  if one is wrong about the present, that is expected — it describes its date.
- **Current truth lives in exactly two places:** the root `README.md` and
  `docs/ROADMAP.md`. If a claim in this folder disagrees with them, they win.
- Design rationale (why the code is shaped the way it is) is *not* history and
  does not live here — it stays with the design docs in `docs/`.
